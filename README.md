## How to Practice

### First round
Do only the 🔥 programs.

### Second round
Do the ⭐ programs.

### Last round
Use 🟡 programs for extra practice.

For interview preparation, understand the logic instead of memorizing the code:

**What is the input? -> What logic do I need? -> Which loop/method should I use? -> What output should I get?**
